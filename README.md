# sql-exercicios

Esse repositório junta os scripts SQL que fui produzindo nas aulas de banco de dados, usando MySQL Workbench. Tem exercício de sala, um trabalho em grupo e um banco que fiz só pra praticar.

## Arquivos

### Aula 2.sql
Primeiro exercício, feito em sala. Cria o banco `gameCollection` com duas tabelas, `games` e `players`, ligadas por chave estrangeira (cada jogador tem um jogo favorito). Inserts e selects simples, pra pegar a sintaxe do MySQL.

### game-collection.sql
Uma versão mais redonda do mesmo banco de jogos, já batizado de `game_collection`. Mais jogos cadastrados e os jogadores apontando pros seus favoritos.

### lista_compras.sql
Banco pequeno pra listar item e preço de compras. Usei pra treinar `create table` com tipo numérico e uns inserts rápidos.

### trabalho-500pts.sql
Trabalho em grupo, valendo 500 pontos, com as tabelas `curso` e `aluno` relacionadas por chave estrangeira. Feito com os colegas Lucas Felipe Silva de Oliveira e Anderson da Silva Melo.
